최신 분석·원자료 재구축 코드, 필드 사전, 벤치마크 설정, 모델 버전·가중치 메타데이터, 표·그림 연결표와 `paper/`의 원고 PDF를 포함합니다. 제공된 PDF는 원본 그대로 복사했습니다. 이번 공개를 위해 코드나 통계 결과를 수정하지 않았으며, 생성형 추론이나 통계 계산도 다시 실행하지 않았습니다.

## 자료 이용 및 비공개 파일

CSMAR 등 이용허가 데이터베이스의 재배포 제한에 따라 기업별 원시값과 파생 재무·통제·수익률·거래상태·규제 변수 및 기업별 입력 파일을 제외했습니다. 기업별 프롬프트, 원시 응답과 파싱 점수, 예측값, 고정 부트스트랩 추출값, 사례별 검증 기록도 공개하지 않습니다. 수치 결과 스냅샷, 실행 로그, 원고 추출·감사 자료와 기존 비공개 목록 파일도 보수적으로 제외했습니다. 제외한 각 원본 경로는 [EXCLUDED_FILES.md](EXCLUDED_FILES.md), 공개본 선택 근거는 [DATA_REVIEW.json](DATA_REVIEW.json)에 기재했습니다.

제한된 재현 자료의 검토를 원하는 연구자는 원고에 기재된 연락처로 교신저자에게 신청할 수 있습니다. 제공 가능 여부는 해당 데이터베이스 이용허가 및 기관 권한에 따릅니다. 이는 유료 자료의 재배포 허가를 의미하지 않습니다. 완전한 검토용 저장소는 비공개로 유지하며, 이 공개본은 별도로 초기화한 Git 이력을 사용합니다.

## 재현에 필요한 조건

이 공개본만으로는 원고의 표를 재현하거나 전체 오프라인 검증을 실행할 수 없습니다. 필요한 이용허가 자료, 보관된 추론 기록, 고정 추출값과 참조 파일이 제외되어 있습니다. 대체 관측값이나 결과 스냅샷은 제공하지 않습니다. 권한 있는 연구자는 `data/DATA_DICTIONARY.csv`, 원자료 재구축 코드 및 `TABLE_FIGURE_MAP_sun21.csv`에 설명된 제한 자료를 복원한 후 기존 실행기를 사용해야 합니다. 원자료는 소속 기관의 정당한 이용권한으로 확보하십시오.

자료 복원 후 사용하는 기존 Python 3.12 실행 명령은 다음과 같습니다.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run_all.py
```

보존된 원자료 설명과 코드는 완전한 비공개 패키지의 경로를 참조합니다. 이러한 참조는 해당 파일을 공개 배포한다는 뜻이 아닙니다. `raw_rebuild/`는 자료 구축·추론 참조 코드입니다. 모델 가중치와 학습된 모델 직렬화 파일은 배포하지 않습니다. `MANIFEST.csv`와 `CHECKSUMS.sha256`는 두 목록 파일 자체를 제외한 공개본 파일을 기록합니다.
