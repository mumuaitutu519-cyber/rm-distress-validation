# CSMAR inputs and frozen model inference

Internal review only; no public redistribution of CSMAR-derived company records or company prompt snapshots. Package snapshot: 2026-11-06; manuscript authors: Sun–Chen–Ryu. No files are inherited merely because they existed in the 26 September package: the active pipeline uses strict_timing outputs for the latest manuscript.

Paid sources and field-level extraction are implemented in 36_build_strict_timing_panel.py and 48_audit_regulatory_data.py:

- CSMAR annual financial extract, local table export 上市公司财务年度数据合并（90-24）.dta, company code/year/report-announcement date, assets/liabilities/income/cash-flow/growth/tangibility/valuation/age/loss fields. Final variables: Size, Lev, ROA, Growth, Cash, Tangibility, TobinQ, FirmAge, Loss.
- CSMAR 特殊处理变动文件215444852.zip, workbook trading-status changes: Symbol, Annoudt, Execudt, Chgtype and status/reason-code fields exactly named in the extraction script. ST/*ST onset, prior state and next-year first transitions are rebuilt from the dated status records bundled in data/derived/.
- 常用控制变量2000_2025_Ver4.1.dta, source explicitly prohibits secondary distribution/resale; company/year control fields and annual report landmarks.
- stock_returns_daily.dta, company, trading date, daily return: lagged return-volatility feature. Regulatory announcement exposures and dated outcome linkage are included as observation-level benchmark inputs.

Exact original provider retrieval dates are not recorded for every historical extract; retained source build logs and source file metadata identify the 2026-08 build vintage. Do not invent a retrieval date. Database/table labels above are the actual retained export labels; licensed institutional SQL table names must be supplied by that institution. These provenance gaps do not prevent this package's analytical recomputation.

Inference is the explicitly exempt expensive step. data/calls contains each unedited reply and its parsed score, keyed to company, representation/variant and model configuration. Prompt snapshots and the seven-dimension protocol templates are in the strict_timing_*prompts*.parquet files and 37_prepare_strict_timing_audits.py / 41_build_information_factorial.py. Use 07_run_revision_llm_audit.py with the recorded logs/configuration to rerun inference.
